# nixie-bedside-console
A tactile, retro-industrial alarm clock using an STM32 board, IN-14 Nixie tubes, a diffused wake-up light bar/lamp, physical controls, and a big red snooze/dismiss button.

## Concept
This project explores the design and build of a bedside alarm clock as a physical control console as opposed a plasticky digital device. The aim is to build something tactile, repairable, warm, and useful.

## Planned Features
- 4-digit IN-14 Nixie tube display
- INS-1 neon colon
- Diffused wake-up light bar/lamp
- Big red snooze/dismiss button
- Physical alarm arm/disarm toggle
- Edit time/neutral/edit alarm selector
- Rotary controls for hour and minute adjustment
- Manual light toggle and light-intensity slider
- STM32-based controller logic

## Design Goals
- Tactile, physical and industrial interaction
- Retro-industrial visual language
- Clear, readable alarm states (using LEDS)
- No app or network dependancy
- Easily replaceable Nixie tube mouting
- Safe high-voltage enclosure design

# Current Status
Concept design, mood board, interaction hierarchy, and early component research.

# Safety
This project does feature high-voltage circuitry for the Nixie tubes, so this section will be enclosed, isolated, and designed so that live contacts are not accessible during normal use.
